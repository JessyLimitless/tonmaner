## 원고의 출처 (2026-09-22)

원고는 저자가 HWP로 쓴 PDF(`source.pdf`, 46쪽)에서 뽑았다. 다시 뽑아야 할 때:

```bash
python tools/pdf-extract.py source.pdf paras.txt        # 문단 복원 (볼드 런은 ⟦ ⟧)
python tools/pdf-convert.py paras.txt out/              # 장별 md + 조판 마크업
python tools/verify-against-pdf.py build/book.epub paras.txt   # 원문 대조
```

(이 책 폴더 안에서 실행.) 원고는 이미 md로 확정됐고 PDF는 참고용이다.
**PDF를 다시 파싱해 md를 덮어쓰지 않는다.** md에 손댄 뒤라면 파싱본이 그 손질을 지운다.
12·13·16장 끝의 `.callout`은 변환 뒤 손으로 감쌌다 — 다시 변환하면 빠진다.

### PDF에서 md로 옮기며 정한 것 (저자 확정)

- PDF에는 5~16장만 있었다. 프롤로그·1~4장·부록은 뒤에 저자가 대화창으로 줬다(위 「진행 상황」).
- **중복된 장은 뒤의 개정본을 쓴다.** 6장·16장은 두 벌 중 뒤 것, 10장·12장은
  `[실전 공시 해부]` 절이 두 벌이라 뒤 것. 12장에 섞여 있던 안내 문장
  ("앞선 12장 원고 후반부에… 풀버전을 덧붙입니다")은 뺐다.
- 부 구성은 처음엔 조판 쪽 제안(3부)이었으나 저자 목차가 와서 4부로 확정했다.
- 원고의 마크다운 잔재 `*"…"*`(8장, 별표 두 쌍)는 별표만 걷었다.

### 원문 그대로 둔 것 (저자 판단 대기)

마침표 뒤 공백이 빠진 곳 세 군데 — 원문이 그렇다. 고치지 않았다.

- 5장 「…물적 확증이다.둘째, 최신 분기보고서의…」
- 15장 「…전산망 필터를 가동해야 한다.가장 먼저 머릿속에…」
- 15장 「…진입 3단계 모델을 가동한다.우선 차트가…」

| 화자 | 동업자가 동업자에게. 냉정·정밀·단정. | 초보를 가르치는 선생. "~를 처음 여는 독자를 위해", "~라는 말이 낯설다면" |
| 설명 | **설명은 남긴다.** 아는 독자는 넘기고 필요한 독자는 읽는다(2026-09-22 저자). 정의는 한 줄로 단정하게, 계산 예시·공시 칸 위치·규정 이름과 연도는 늘린다 | 독자 수준을 가정하는 말 — "낯설다면", "처음이라면", "모르는 독자를 위해", "쉽게 말하면" |
| 비유 | 저자의 시그니처는 유지 — 장부 부검의, 설거지, 세력/개미, 용수철, 폭탄 타이머 | 한 문단에 비유 둘 이상. 피·학살·도살장·산화·고혈 같은 유혈 표현은 장당 한 번 이하 |
| 단정 | 근거가 있는 만큼만. "거의 예외 없이", "높은 확률로" | "100% 확률로", "무조건", "절대" |
| 영어 | 금융 용어는 병기 (델타, 스프레드, ROIC, D-2) | 구호성 영어 — Strong Buy, Run Away, Mega Trend, Free Ride |
| 문장 | 짧게. 한 문장에 판단 하나. 명령형은 "~한다/~해야 한다"로 통일 | "당신은", "~하라!", 수사의문 연발 |
| 반복 | 한 신호는 한 장에서 깊게, 다른 장에서는 "14장"처럼 참조 | 같은 설명을 장마다 다시 |
| 라벨 | `.lead` 머리표는 한국어 판정어 — 진입 / 관망 / 이탈 / 검증 | 영어 슬로건 머리표 |

**적용 결과 (2026-09-22 오후)** — 위반 표현 70여 곳을 문장 단위로 고쳤다(독자 수준 가정 문구 18, "당신" 9, 유혈 표현 22→장당 1 이하,
영어 구호 라벨 14, "100% 확률"·"무조건" 4). 설명·계산·표는 전부 그대로. 본문 글자 수는 83,600 → 83,000 안팎으로 사실상 변화 없음.
`_old/manuscript-before-tone/`에 고치기 전 원고가 있다.

이 기준은 **저자 원문에도 적용한다** (2026-09-22 저자가 "전체적으로 다시 다듬어 보자"고 명시 요청).
그러므로 이 시점부터 「원문 문장을 고치지 않는다」 원칙은 이 책에서 해제되고, PDF 문단 대조 도구는 더 이상
통과 기준이 아니다. 대신 다듬기 전 원고를 `_old/manuscript-before-tone/`에 남긴다.

## 이 책만의 조판

장마다 같은 리듬으로 흐른다. 마크업도 그 리듬을 따른다.

| 원고 | 마크업 |
|---|---|
| `5장. [질문 1] 왜 발행하는가? (자금 조달의 목적)` | `# [05]{.ch-num} 왜 발행하는가?` + `::: {.ch-sub}` 질문 1 · 자금 조달의 목적 |
| `[시그널 판독] …` / `[실전 공시 해부] …` | `## [시그널 판독]{.sec-tag} …` — 꼬리표를 제목 위에 작게 얹는다 |
| `Case A: 제목 - 부제` | `### [Case A]{.case} 제목 — 부제` — 강조색 표찰 |
| 볼드 소제목 한 줄 | `### ` |
| 본문 볼드 런 | `[…]{.dot}` 방점 — **DART·KRX 문서·칸·규정 이름과 책이 정의한 판정 신호 이름에만.** 저자가 지은 이름표 명사구에는 안 찍는다(2026-09-22 가독성 처방 4) |
| 장 끝 경구 (12·13·16장) | `::: {.callout}` |
| 장 앞 간지 | `# [05]{.ch-num} 제목 {.ch-divider .unlisted}` + `::: {.divider-lead}` 부제 줄 + 훅 한 문장 |
| `1단계. 발행:` 같은 문단 머리 라벨 (1~4장) | `[1단계. 발행:]{.lead}` |
| 비교표 | `::: {.table-wrap}` |

`.sec-tag`·`.case`·`.lead`·`.ch-divider`·`.interleaf`는 이 책 `override.css`에만 있다. 공용 CSS는 건드리지 않았다.
